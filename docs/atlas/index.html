Invariants

The load-bearing rules, from CLAUDE.md, the roadmap doctrine and the control-loop design. Each names the components it governs.

  1. H1: AI-generated code is never gated by AI self-review. Reviewer
  2. H2: any adversarial prompt-body change re-runs calibration and records the delta. Calibration, Reviewer, SecurityReviewer
  3. H3: prompt version and snapshot hash move together in one diff. Reviewer, SecurityReviewer
  4. H4: every done claim states what was tested versus assumed.
  5. Doctrine: integrate at the edges, build only thin middles.
  6. Doctrine: enforcement reads artifacts, never agent self-report. AdequacyGate, Distiller, FixturesOracle, MechanicalVerifier, PolicyEnvelope, Reviewer, SecurityReviewer
  7. Doctrine: autonomy is earned, bounded, revocable; the bundle may only withhold. AutonomyLadder, PolicyEnvelope
  8. Doctrine: no assumed numbers; advisory first, graduate on the operator's judgement. AdequacyGate, AutonomyLadder, Calibration, Dampener, FlowControl, HealthTrending, Proposals, ServeDaemon
  9. Doctrine: the human is a role, not a bottleneck; boundary conditions route to the inbox. FlowControl, Inbox, OperatorContext, SafeMode, ServeDaemon, Steering
  10. Doctrine: the first-class phase count is frozen; new evaluators land inside a phase. Pipeline, Scheduler
  11. Doctrine: new outcome surfaces reuse the shared disposition; existing enums are not retrofitted. Pipeline, Scheduler
  12. Loop rule: what acts never measures its own result (a measurement written by the actuator is not a measurement). Dampener, EngineerLoop, MechanicalVerifier, PRD, Pipeline, RetryContext, Reviewer, SecurityReviewer
  13. Loop rule: every component runs by hand first; a sensor reachable only through a factory run cannot be tuned. EngineerLoop, MechanicalVerifier, Sense
  14. Record rule: the filesystem is the event bus; sinks are observability, never control flow; the dashboard is a view. Dashboard, EventBus, ProgressLog, Reducer
  15. Trust boundary: control state lives outside the agent-reachable tree; unreadable control state fails closed. AutonomyLadder, SafeMode, ServeDaemon, SpendLedger, StateDir
