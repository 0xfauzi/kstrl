Eight status marks, drawn, one meaning each: needs you, working, waiting, agreed, disagreed, merged, skipped, not measured.

Use `<span class="k-mk pass"></span>` (16px), add `sm` for 12px inline, or `lg` for 24px where a mark is the subject (this card). Each is coloured by its token (`you`, `work`, `text-3`, `pass`, `fail`). Always pair a mark with a word the first time it appears on a surface. "Not measured" is for a check that did not run; never replace it with a pass.
