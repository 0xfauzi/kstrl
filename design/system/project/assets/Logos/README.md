The kestrel mark: a hovering kestrel drawn with four straight-edged polygons on a 64 by 64 grid. `kstrl-mark.svg` is single ink `#1a1a1a`, for light grounds. `kstrl-mark-dark.svg` is single ink `#e8e6e3`, for dark grounds such as `background`. Neither ink is a token: both are neutral greys, not the warm ramp. Use the mark at 16px or larger, beside the word `kstrl` set in `mono` bold. Do not recolour, outline, rotate or redraw it.
